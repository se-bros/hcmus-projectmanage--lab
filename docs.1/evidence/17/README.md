## 3. Các bằng chứng & số liệu then chốt cần chỉ ra trên tài liệu

- **Dữ liệu thực tế:** Tổng giờ thực tế Actual = 184 giờ-người so với Ước lượng 190 giờ-người (tiết kiệm 6 giờ, độ lệch -3.1%).
- **Chỉ số luồng:** Lead Time trung bình 4.2 ngày, Cycle Time 2.1 ngày, không có card nào bị tắc nghẽn quá 5 ngày.
- **Kiểm soát tiến độ qua GitHub Projects, Pull Requests và Project Log hàng ngày.:**
- **Báo cáo giữa kỳ minh chứng dự án đạt 100% mục tiêu giai đoạn 1.:**

## 4. Khung hướng dẫn trả lời vấn đáp (WHAT — HOW — WHY — EVIDENCE)

- **WHAT (Khái niệm & Nội dung):** Quy trình thu thập dữ liệu hiệu suất, so sánh thực tế với kế hoạch và thực hiện các biện pháp điều chỉnh cần thiết.
- **HOW (Quy trình thực hiện):** Cập nhật board hàng ngày → Ghi nhận Project Log sau mỗi task → Phân tích biểu đồ CFD/Burndown → Phát hiện độ lệch → Báo cáo tình trạng định kỳ.
- **WHY (Lý do & Giá trị):** Phát hiện sớm nguy cơ trễ hạn hoặc vượt tải để có biện pháp can thiệp kịp thời trước khi quá muộn.
- **EVIDENCE (Minh chứng chỉ tay):** Chỉ vào Bảng Kanban thực tế, Bảng theo dõi Actual Hours trong Project Log và Biểu đồ Burndown/CFD.
